# Портфолио дизайнера интерьера

Одностраничный адаптивный сайт в эстетике современного интерьерного журнала. Стек: React 18, Vite 5, JavaScript и CSS.

## Что находится в проекте

- главный экран с интерьерной фотографией;
- раздел «Обо мне»;
- целевая аудитория и принципы работы;
- галерея визуальных ориентиров с увеличением изображений;
- цветовая палитра с копированием HEX-кодов;
- фирменный знак;
- презентационная композиция визитки и блок контактов;
- адаптивное меню, плавная навигация и деликатные появления блоков;
- локальные изображения в `public/images`.

> Изображения извлечены из файла `portfolio_polina.pptx`: обложка, портрет, фотографии целевой аудитории и интерьерные референсы, фактуры палитры, логотип и визитка. Некоторые фотографии в оригинальной презентации используются более чем в одном слайде, поэтому на сайте они также могут повторяться. На оригинальной визитке в исходной презентации напечатан номер `+78000000000` и есть QR-код; проверь и замени их, если это макетные данные, перед публикацией.

## 1. Установка Node.js на Windows

1. Откройте <https://nodejs.org/> и установите актуальную LTS-версию Node.js.
2. Закройте и заново откройте Visual Studio Code.
3. Откройте Terminal → New Terminal и проверьте установки:

```bash
node -v
npm -v
```

## 2. Распаковка и запуск

1. Распакуйте архив `portfolio-interior.zip`.
2. Откройте VS Code → **File → Open Folder** и выберите папку `portfolio-interior`.
3. Откройте терминал VS Code: **Terminal → New Terminal**.
4. Установите зависимости:

```bash
npm install
```

5. Запустите локальный сервер разработки:

```bash
npm run dev
```

6. Откройте адрес, показанный в терминале — обычно <http://localhost:5173/>.

Чтобы остановить сервер, вернитесь в терминал и нажмите `Ctrl + C`.

## 3. Проверка production-сборки

```bash
npm run build
npm run preview
```

Первая команда создаёт production-версию в папке `dist`, вторая запускает предпросмотр. После запуска откройте адрес, показанный в терминале (обычно <http://localhost:4173/>).

## 4. Где менять тексты, цвета и контакты

### Тексты

Файл `src/data/content.js` содержит имя автора, образование, тексты секций, тезисы, данные галереи, палитру и контакты.

### Изображения

Локальные изображения находятся в `public/images/`:

- `hero-interior.webp` — фотография с обложки;
- `designer-portrait.webp` — портрет автора из слайда «Обо мне»;
- `audience-01.webp` — `audience-03.webp` — изображения целевой аудитории;
- `style-01.webp` — `style-04.webp` — интерьерные референсы из слайда «Стиль»;
- `texture-brick.webp`, `texture-concrete.webp`, `texture-wood.webp`, `texture-stone.webp`, `texture-charcoal.webp` — фактуры из слайда «Цветовая гамма»;
- `logo-polina.webp` и `logo-polina-original.jpg` — логотип;
- `business-card.webp` и `business-card-original.jpg` — оригинальная визитка.

Если заменяете изображение, можно сохранить прежнее имя файла. Тогда код менять не требуется. Для нового имени обновите путь в `src/data/content.js` или соответствующем компоненте в `src/sections/`.

**Портрет автора:** используется исходное изображение со второго слайда презентации. Путь задаётся в `about.portrait` внутри `src/data/content.js`.

### Цвета и шрифты

Основные цвета и адаптивные стили находятся в `src/styles/global.css`, в блоке `:root`. Текущий стиль построен на графитовом фоне, кремовых поверхностях и тёплых натуральных оттенках. Шрифты подключаются в `index.html`; для их загрузки во время просмотра требуется подключение к интернету. При отсутствии сети браузер использует запасные системные шрифты.

### Контакты

Откройте объект `contacts` в `src/data/content.js` и заполните `phone`, `email`, `telegram` и/или `vk`. Пустые поля намеренно не выводятся на сайте, чтобы не публиковать выдуманные контактные данные.

## 5. Загрузка на GitHub

Создайте новый репозиторий на <https://github.com/>. В терминале VS Code, находясь в папке проекта, выполните (замените `ВАШ_ЛОГИН` на свой логин GitHub):

```bash
git init
git add .
git commit -m "Initial interior portfolio"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/portfolio-interior.git
git push -u origin main
```

Если Git попросит войти, пройдите авторизацию. Папки `node_modules` и `dist` исключены через `.gitignore`.

## 6. Публикация на Render

1. Откройте <https://render.com/> и войдите через GitHub.
2. Выберите **New → Static Site**.
3. Подключите репозиторий `portfolio-interior`.
4. Укажите следующие настройки:

- **Build Command:** `npm install && npm run build`
- **Publish Directory:** `dist`

5. Нажмите **Create Static Site** и дождитесь завершения сборки.
6. Откройте URL, который выдаст Render. Реальная публичная ссылка появится только после успешного деплоя.

После `git push` в подключённую ветку Render обычно автоматически запустит новое развёртывание.

## 7. Перед публикацией

- убедитесь, что изображения правильно отображаются на компьютере и телефоне;
- проверьте номер телефона и QR-код на изображении визитки перед публикацией;
- подтвердите ФИО и при необходимости исправьте `author.name`;
- заполните реальные контактные данные;
- проверьте сайт на компьютере и смартфоне;
- выполните `npm run build` перед загрузкой обновлений.
